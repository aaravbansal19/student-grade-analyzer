Student Grade Analyzer

Overview : This project analyzes student grade data using Python. It reads a CSV file, cleans missing values, provides a statistical report, identifies the top and bottom performers, and produces visualizations of the data using graphs. 

Features : 
- Reads student data from a CSV file
- Removes missing values
- Calculates mean, median, standard deviation, max, and min.
- Finds the top 3 and bottom 3 students
- Counts the students above and below average
- Creates a bar graph with a class average line
- Creates a histogram of the grade distribution
- Saves the graphs as image files

Methods used :
- Python
- pandas
- matplotlib
